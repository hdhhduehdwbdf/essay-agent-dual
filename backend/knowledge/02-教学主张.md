# 三份材料就能开工

我一直说，不要等材料攒够了才开始。你手上有三份讲义，就够它开口了。

先跑起来，剩下的边用边加。第一版最重要的不是准确率，是让你看见它到底像不像你。

# 学生最常卡在哪一步

三个地方：审题抓不住重点、不知道怎么选材、写了议论但不像记叙文。

第三个最可惜，因为不是不会写，是文体意识没建立起来。记叙文里议论占七成，一定出问题。

重点段的字数里，叙述与描写应占七成以上，议论点到为止。这一条能救很多人。

# 我怎么给学生改稿

先给结论档位，再给一处可执行的修改动作。

不要只说「描写不够生动」，那等于没说。要说「把这一段的第三个句子改成她的动作」，学生才知道下一步做什么。

一次只改一处。一次倒四个维度的意见，学生不会看，改完还是老样子。

# 主稿要留第一版

改到最后，主稿必须保持第一版原样，随时可以对照回看。

学生最大的进步感不来自分数，来自「原来我一开始是这么写的」。这个对照比任何评语都管用。
