# 审题：先找限定词，再定落点

审题不是找题眼，是确认这个题目在问什么和什么的关系。关系找对了，立意才有落点；关系找错了，写得再漂亮也是偏的。

我从不教模板，我教你怎么想。先圈出限定词：谁、在什么关系里、发生了什么变化。这三样定下来，落点就自己浮出来了。

以「和解」为例，题目给了六种落地：完美的结局、故事的开头、消除争议的方案、无奈的选择、需要和解、拒绝和解。结局和开头是两条完全不同的路，动笔前必须先选一条。

# 立意：要双向，不要单向

最容易丢分的是写成单向道歉：一方认错，另一方原谅。这样写，立意天花板就在二类。

写清双方的让步动作，立意才站得住。谁也不是全对，谁也不是全错，两个人各自退了一步，这才是和解真正的样子。

单向道歉 → 三类；各自退让 → 二类上；双向让步并留下余味 → 一类下。

# 选材：真、小、有转折

素材要真、要小、要有一个能写的变化瞬间，三者具备才撑得起重点段。

真的发生过，切口够小，含一个可写的变化瞬间。这三条是硬标准。虚构的大事件不如真实的小事件。

避开高频套路：绝症、车祸、亲人离世、转学重逢。这些题材不是不能写，是十个人写九个雷同，阅卷老师看不出你。

# 结构：一条情节链，三个节拍

起因、冲突顶点、松动瞬间，中间埋一次「停顿」，为结尾的场景收束留位置。

更要紧的是停顿。在冷战和和好之间，要有一次你以为不会好了的时刻。没有停顿，反转是平的，和解就没有重量。

高级结构有四种：倒叙设置悬念、蓄势上升式、曲转反复式、物线贯穿。先用好三段式，再谈高级结构。

# 描写：把情绪换成动作

把抽象情绪换成可观察的动作、神态与环境细节，读者才看得到画面。

「我很难过」这四个字什么都不是。她怎么收的碗，碗碰在池子里什么声音，她有没有看你——写这些，不要写你难过。

描写要聚焦中心：写的每一处细节都要服务于这段要表达的东西。详略得当，比写得漂亮重要。

六种描写方法：外貌、神态、动作、语言、心理、环境。挑两类写透，不要平均用力。

# 议论文和记叙文怎么选

看题目要你做什么。题目要你讲一个过程，就写记叙文；题目要你判断一个道理，就写议论文。

记叙文靠事，议论文靠理。选错文体，写得再好也是偏的。考场时间紧的时候，选你手上素材更实的那一种。

# 关于用 AI 写作文

AI 能帮你改句子、帮你找素材，但想不出你生活里那件事。那件事只有你自己有，这才是你的分。

参考别人的句子可以，抄别人的经历不行。阅卷老师看的不是文采，是你有没有真的活过。
